# AI Voice Box (ESP32-S3)

语音盒子固件：说话 → 识别 → 对话 → 语音回复，0.96" OLED 显示余额、时间、状态。

## 当前版本：v60

## 刷哪个文件（重要）

| 文件 | 用途 | 刷写偏移 |
|---|---|---|
| `AIBox_full.bin` | **USB 救砖 / 首次烧录**（含 bootloader + 分区表 + 应用） | **`0x0`** |
| `AIBox.ino.bin` | 仅应用镜像，给 OTA 用（板子自己下载升级） | `0x10000` |

⚠️ **把 `AIBox.ino.bin` 按 `0x0` 刷进去，板子一定起不来** —— 它只是应用段，前面缺 bootloader 和分区表。

## v60 修复的关键问题

1. **镜像末尾的 `hash_appended` 标记必须为 0**
   打包工具会把它置 1，但尾部 32 字节并不是真 SHA256，
   于是芯片 ROM 开机比对必然失败：`SHA-256 comparison failed` → 卡死黑屏。
   **所有 bin 都已置 0。**
2. **softAP 密码必须 ≥ 8 位**
   原来用 6 位密码，`WiFi.softAP()` 会静默失败，芯片退回自己的默认开放热点 `ESP_XXXXXX`。
3. 开机不再自动联网查更新（救砖版绝不能"开机就下载固件覆盖自己"）

## 开机热点

- SSID `AIBox-Setup` / 密码 `12345678`
- 开机即开，连上 WiFi 后自动关闭
- 配置页：`http://192.168.4.1`

## 按键

| 键 | 长按 | 短按 |
|---|---|---|
| K1 (∧) | 5 秒 → 切换到另一个分区的固件（OK/NO 确认） | — |
| K2 (∨) | 5 秒 → 同上 | — |
| K3 (#) | 3 秒 → 强制进配网 | 待机页进菜单 |
| K4 (米字) | 按住说话 | — |

## 硬件

ESP32-S3 N16R8 / SSD1306 0.96" OLED (I2C: SDA=8, SCL=9) /
INMP441 麦克风 (SCK=11, WS=10, SD=12) / MAX98357 功放 / WS2812 (GPIO48)
